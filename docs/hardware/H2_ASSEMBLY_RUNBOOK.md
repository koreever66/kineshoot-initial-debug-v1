## 1. 电池与 TP4057 断电检查

此阶段不接 ESP32，不接升压模块，不接负载。

### 1.1 电池电压

分别测量两块电池：

| 电池 | 预期 | 实测 |
|---|---:|---:|
| B1 | 3.0 到 4.2V | 3.88V |
| B2 | 3.0 到 4.2V | 3.92V |

注意电池红黑线和保护板极性，不要只看线色猜测极性。

### 1.2 TP4057 焊盘

先在断电状态下确认板上的丝印：

- 找到 `BAT+` 焊盘组。
- 找到 `BAT-` 焊盘组。
- 同极性焊盘内部应导通。
- `BAT+` 与 `BAT-` 之间不应导通。

检查：

- [x] 两个 `BAT+` 之间导通。
- [x] 两个 `BAT-` 之间导通。
- [x] `BAT+` 与 `BAT-` 不导通。
- [x] Type-C 口没有明显变形或短路。

确认日期：2026-09-18。B1、B2 电压和 TP4057 焊盘通断已由硬件端确认。

如果丝印和用户观察的左右两组关系不一致，先停下并拍照确认，不要焊。

要求：

- [x] 电池正极焊到 PH2.0 2P 一侧，负极焊到另一侧。
- [x] 焊接前先套热缩管，焊完后再收缩。
- [x] 焊接后逐根通断确认，不依赖线色。

## 4. ICM-20948 线束

固定接口：

```text
ICM VCC       -> ESP32 3V3
ICM GND       -> ESP32 GND
ICM SDI/SDA   -> ESP32 GPIO8
ICM SCLK/SCL  -> ESP32 GPIO9
ICM NCS       -> ESP32 3V3
ICM AD0       -> ESP32 GND

I2C address = 0x68
I2C clock   = 50kHz
WHO_AM_I    = 0xEA
```

4P PH2.0 线序固定：

```text
Pin 1 = VCC = 3V3
Pin 2 = GND = 公共地
Pin 3 = ICM SDI/SDA = GPIO8
Pin 4 = ICM SCLK/SCL = GPIO9
```

ICM 端就近处理：

```text
NCS -> 3V3
AD0 -> GND
```

检查：

- [ ] 4P 两端线序一致。
- [ ] VCC 对 GND 不短路。
- [ ] ICM SDI/SDA 对 GND 不短路。
- [ ] ICM SCLK/SCL 对 GND 不短路。
- [ ] NCS 与 3V3 导通。
- [ ] AD0 与 GND 导通。
- [ ] 传感器和主板共地。

先用电脑 USB 单独给 ESP32 供电，读取 `0x68` 和 `WHO_AM_I=0xEA`。此步通过前不要接电池供电链。

2026-09-19 ICM 4P 静态初始化记录：

```text

FILESYSTEM_MOUNT_OK
FILESYSTEM,free=1433600,total=1441792
IMU_INIT,status=All is well.

```

结论：ICM 4P 线束已通过初始化。`IMU_INIT,status=All is well.` 表示 SparkFun 库完成 `begin()` 和 `checkID()`，`WHO_AM_I` 已匹配 `0xEA`；I2C 使用 `0x68`、`50kHz`。此记录尚不等同于 10 秒静态采集通过。

## 5. 主电源链接线

当前首版主路径：

```text
500mAh 电池 B+ -> PH2.0 2P -> TP4057 BAT+
500mAh 电池 B- -> PH2.0 2P -> TP4057 BAT-

TP4057 另一组 BAT+ -> SS-12E07G4 3A 开关 -> TPS61088 IN+
TP4057 另一组 BAT- ------------------------> TPS61088 IN-

TPS61088 OUT+ 5V -> ESP32 5V
TPS61088 OUT-    -> ESP32 GND
```

如果 TP4057 的两组 BAT 焊盘都已经占用，不需要拆出新的 BAT 焊盘。直接把 `SS-12E07G4` 串到 TP4057 输出正极和 TPS61088 VIN+ 之间已有的红线上：

```text
TP4057 输出 BAT+ -- 红线 -- 开关中心脚
开关一个外侧脚 -- 红线 -- TPS61088 VIN+
TP4057 输出 BAT- --------- 黑线 --------- TPS61088 GND
```

开关只切正极，黑色地线保持直连。1P2T 开关只使用中心脚和一个外侧脚，另一个外侧脚空置；先按通断档确认两个使用脚在开关 ON 时导通、OFF 时断开。

当前首版不使用：

```text
P-MOS
AO3415
100k 电阻
1k 电阻
SS12D07VG4 作为主电流路径
```

规则：

- [ ] SS-12E07G4 接在电池正极路径，不切 3.3V。
- [x] TPS61088 出厂已配置为固定 5V；空载实测 5.01V，不再修改 5V、9V、12V、ADJ 或 PWM 焊盘。
- [ ] TPS61088 EN 不作为主断电开关。
- [ ] 不用 SS12D07VG4 承受升压输入主电流。
- [ ] 电脑 USB 与电池输出不能同时接 ESP32。
- [ ] USB 烧录或导出数据时，先关闭电池路径。
- [ ] TP4057 充电时关闭负载。

### 6.2 ESP32 启动

1. 关闭开关。
2. 将 TPS61088 OUT+ 接 ESP32 5V，OUT- 接 ESP32 GND。
3. 打开开关。
4. 确认 GPIO48 RGB 蓝色常亮，只有蓝灯不亮时才按一次 RST。
5. 进入 10 秒记录流程并观察电压。

验收：

- [ ] 启动和记录期间输出不低于约 4.85V。
- [ ] 无反复复位。
- [ ] 无蓝灯熄灭后自动恢复的掉电现象。
- [ ] SS-12E07G4 两端没有明显烫手或可见压降异常。
- [ ] 连续开关 20 次无复位、无电池保护板跳闸。

如果 4.85V 门槛不过，先停止真实投篮准备，记录最低电压和发生时刻。
