## 0. 首日开工检查

先不要接电池到整机，不要同时连接电脑 USB 和电池输出。

需要确认：

- [ ] 有数字万用表，通断档和 DC 电压档可用。
- [ ] 有电烙铁、焊锡、助焊剂、热缩管和剥线工具。
- [ ] 有纸胶带或标签，用来标记线序。
- [ ] 桌面绝缘，电池和裸露焊点不接触金属。
- [ ] 拍摄物料正面和接口丝印照片，照片不包含姓名、电话、地址。

## 1. 电池与 TP4057 断电检查

此阶段不接 ESP32，不接升压模块，不接负载。

### 1.1 电池电压

分别测量两块电池：

| 电池 | 预期 | 实测 |
|---|---:|---:|
| B1 | 3.0 到 4.2V | 3.88V |
| B2 | 3.0 到 4.2V | 3.92V |

注意电池红黑线和保护板极性，不要只看线色猜测极性。

### 1.2 TP4057 焊盘

先在断电状态下确认板上的丝印：

- 找到 `BAT+` 焊盘组。
- 找到 `BAT-` 焊盘组。
- 同极性焊盘内部应导通。
- `BAT+` 与 `BAT-` 之间不应导通。

检查：

- [x] 两个 `BAT+` 之间导通。
- [x] 两个 `BAT-` 之间导通。
- [x] `BAT+` 与 `BAT-` 不导通。
- [x] Type-C 口没有明显变形或短路。

确认日期：2026-09-18。B1、B2 电压和 TP4057 焊盘通断已由硬件端确认。

如果丝印和用户观察的左右两组关系不一致，先停下并拍照确认，不要焊。

## 2. 电池 PH2.0 2P 线束

目标线束：

```text
电池 B+  -> PH2.0 2P 一侧
电池 B-  -> PH2.0 2P 另一侧
```

要求：

- [x] 电池正极焊到 PH2.0 2P 一侧，负极焊到另一侧。
- [x] 焊接前先套热缩管，焊完后再收缩。
- [x] 焊接后逐根通断确认，不依赖线色。
- [x] 电池端和 TP4057 端使用匹配的公母头，避免正负极插反。
- [x] 焊点附近留 1 到 2cm 柔性缓冲，不让拉力直接落在焊盘上。

完成后的第一目标不是接 ESP32，而是独立充电测试。

## 3. TP4057 独立充电测试

接线只允许：

```text
电池 -> PH2.0 2P -> TP4057 BAT+ / BAT-
TP4057 Type-C <- 5V USB 充电器
```

此时：

- 不接 ESP32。
- 不接 TPS61088。
- 不接 SS-12E07G4 负载侧。
- 充电时保持观察，不要放在无人看管的封闭软袋中。

检查：

- [x] 充电红灯亮。
- [x] 电池电压缓慢上升，最终落在 4.15 到 4.20V 即可；不要求正好 4.20V。
- [x] TP4057 不出现明显烫手。
- [x] 电池不鼓包、不发烫、不异味。
- [x] 充电完成后绿灯亮。

2026-09-18 实测记录：

```text
B1 起始电压：                 3.89V
2.5 分钟：                    4.17V
5 分钟：                      4.17V
13.5 分钟：                   4.18V
15 分钟：                     4.18V
约 60 分钟：                  绿灯亮，4.16V
模块和电池温升：              无异常
```

充电电源为 10000mAh 充电宝，5V 输出。绿灯表示充电终止条件已满足；4.16V 属于可接受结果，后续以开路静置电压记录为准。

如果出现异常发热、异味、电压下降或保护板断开，立即断开 USB，停止测试。

## 4. ICM-20948 线束

固定接口：

```text
ICM VCC       -> ESP32 3V3
ICM GND       -> ESP32 GND
ICM SDI/SDA   -> ESP32 GPIO8
ICM SCLK/SCL  -> ESP32 GPIO9
ICM NCS       -> ESP32 3V3
ICM AD0       -> ESP32 GND

I2C address = 0x68
I2C clock   = 50kHz
WHO_AM_I    = 0xEA
```

4P PH2.0 线序固定：

```text
Pin 1 = VCC = 3V3
Pin 2 = GND = 公共地
Pin 3 = ICM SDI/SDA = GPIO8
Pin 4 = ICM SCLK/SCL = GPIO9
```

ICM 端就近处理：

```text
NCS -> 3V3
AD0 -> GND
```

检查：

- [ ] 4P 两端线序一致。
- [ ] VCC 对 GND 不短路。
- [ ] ICM SDI/SDA 对 GND 不短路。
- [ ] ICM SCLK/SCL 对 GND 不短路。
- [ ] NCS 与 3V3 导通。
- [ ] AD0 与 GND 导通。
- [ ] 传感器和主板共地。

先用电脑 USB 单独给 ESP32 供电，读取 `0x68` 和 `WHO_AM_I=0xEA`。此步通过前不要接电池供电链。

## 5. 主电源链接线

当前首版主路径：

```text
500mAh 电池 B+ -> PH2.0 2P -> TP4057 BAT+
500mAh 电池 B- -> PH2.0 2P -> TP4057 BAT-

TP4057 另一组 BAT+ -> SS-12E07G4 3A 开关 -> TPS61088 IN+
TP4057 另一组 BAT- ------------------------> TPS61088 IN-

TPS61088 OUT+ 5V -> ESP32 5V
TPS61088 OUT-    -> ESP32 GND
```

当前首版不使用：

```text
P-MOS
AO3415
100k 电阻
1k 电阻
SS12D07VG4 作为主电流路径
```

规则：

- [ ] SS-12E07G4 接在电池正极路径，不切 3.3V。
- [x] TPS61088 出厂已配置为固定 5V；空载实测 5.01V，不再修改 5V、9V、12V、ADJ 或 PWM 焊盘。
- [ ] TPS61088 EN 不作为主断电开关。
- [ ] 不用 SS12D07VG4 承受升压输入主电流。
- [ ] 电脑 USB 与电池输出不能同时接 ESP32。
- [ ] USB 烧录或导出数据时，先关闭电池路径。
- [ ] TP4057 充电时关闭负载。

## 6. 升压和带载验证

### 6.1 空载

1. 电池接 TP4057。
2. 开关尚未接入时，可先把 TP4057 空闲 BAT+ / BAT- 临时接到 TPS61088 VIN / GND。
3. 不修改 TPS61088 的 5V、9V、12V、ADJ、PWM 焊盘。
4. 不接 ESP32，不接任何输出负载。
5. 万用表测 TPS61088 VOUT 对 GND。

验收：

- [x] 空载输出约 5.00V。
- [x] 输出没有明显周期性跌落。
- [x] 模块不出现明显发热。

2026-09-18 实测记录：

```text
输入电池电压：                4.15V
TPS61088 VOUT 对 GND：        5.01V
5V 跳线是否手工短接：         否，出厂固定 5V 配置已生效
ESP32 是否接入：              否
输出负载：                    无
模块温升：                    无异常
```

结论：TPS61088 固定 5V 空载测试通过。左边圆形焊点和红框跳线都不要动。

### 6.2 ESP32 启动

1. 关闭开关。
2. 将 TPS61088 OUT+ 接 ESP32 5V，OUT- 接 ESP32 GND。
3. 打开开关。
4. 确认 GPIO48 RGB 蓝色常亮，只有蓝灯不亮时才按一次 RST。
5. 进入 10 秒记录流程并观察电压。

验收：

- [ ] 启动和记录期间输出不低于约 4.85V。
- [ ] 无反复复位。
- [ ] 无蓝灯熄灭后自动恢复的掉电现象。
- [ ] SS-12E07G4 两端没有明显烫手或可见压降异常。
- [ ] 连续开关 20 次无复位、无电池保护板跳闸。

如果 4.85V 门槛不过，先停止真实投篮准备，记录最低电压和发生时刻。

## 7. 机械装配

### 7.1 腕部传感器单元

- [ ] ICM 放入 `5 × 3.5 × 1.8cm` 传感器盒。
- [ ] 盒底加 2mm EVA。
- [ ] 盒子固定在腕横纹向手肘方向 2 到 4cm。
- [ ] 盒子箭头每次朝向手肘。
- [ ] 线束入口先固定，再进入盒子。

### 7.2 前臂单元

- [ ] ESP32、TP4057、开关、TPS61088 和电池先单层摆放在 `10 × 8cm` 软袋中。
- [ ] 电池靠近手肘，模块靠近手腕侧，避免重量集中在腕部。
- [ ] 模块之间加 EVA 或薄泡棉。
- [ ] 用 5cm 前臂绑带固定，避开肘窝。
- [ ] USB-C 口保持可访问。

## 8. 最终测试门槛

真实投篮前必须全部通过：

- [ ] 10 秒静止测试。
- [ ] 小幅动态测试。
- [ ] 无复位。
- [ ] 无全零。
