## 2. 固定接口

```text
ICM VCC  -> ESP32 3V3
ICM GND  -> ESP32 GND
ICM SDA  -> ESP32 GPIO8
ICM SCL  -> ESP32 GPIO9
ICM NCS  -> ESP32 3V3
ICM AD0  -> ESP32 GND

I2C address = 0x68
I2C clock   = 50kHz
WHO_AM_I    = 0xEA
```

禁止：

- `0x69` 或 `0x0C` 作为长期主地址。
- `NCS` 或 `AD0` 悬空。
- 切换或旁路 3.3V 电源路径。
- 改为软件未批准的连接器线序。

## 3. 连接器和线序

连接器：PH2.0 2.0mm 4P 公母带线。

```text
Pin 1 = VCC = 3V3
Pin 2 = GND = 公共地
Pin 3 = SDA = GPIO8
Pin 4 = SCL = GPIO9
```

ICM 端就近固定：

```text
ICM NCS -> 3V3
ICM AD0 -> GND
```

NCS 和 AD0 固定后不需要 6P 连接器。4P 线长优先 10 到 15cm，最多先不超过 20cm。焊接后用万用表逐根检查，不能只靠线色。

## 4. 接线图

```text
                         +----------------+
ESP32-S3 3V3 -----------| PH2.0 4P Pin 1 |-------- ICM VCC
ESP32-S3 GND -----------| PH2.0 4P Pin 2 |-------- ICM GND
ESP32-S3 GPIO8 ---------| PH2.0 4P Pin 3 |-------- ICM SDA
ESP32-S3 GPIO9 ---------| PH2.0 4P Pin 4 |-------- ICM SCL

ESP32-S3 3V3 ------------------------------ ICM NCS
ESP32-S3 GND ------------------------------ ICM AD0

ICM-20948 和 ESP32-S3 必须共地
```

## 5. 机械固定

### 腕部传感器单元

- ICM 放入 `5cm × 3.5cm × 1.8cm` 小盒。
- 盒底贴 2mm EVA。
- 盒子背面贴魔术贴，固定到 3.8cm 腕带。
- 位置：腕横纹向上约 2 到 4cm。
- 盒子画箭头，箭头始终朝向手肘。

### 前臂电源和主控单元

- 第一版把 ESP32、TP4057、电池放入 `10cm × 8cm` 布艺软袋。
- 前臂使用 5cm 绑带，位置约在腕横纹向上 6 到 10cm，避开肘窝。
- `10cm × 7cm × 2.3cm` 主控盒只用于运输和台架测试，不作为投篮佩戴外壳。
- 袋内电池和主板之间加 EVA 或薄泡棉，防止互相撞击。

## 6. 电源路径和开关

最低工作量替代方案：

```text
TP4057 输出 BAT+ -> SS-12E07G4 3A开关 -> TPS61088 IN+
TP4057 输出 BAT- ----------------------> TPS61088 IN-
```

如果该开关确认可以在 3.7V DC 下稳定承载 1A，则不需要 P-MOS、100k、1k 或 AO3415。

当前低工作量方案仍在筛选合格成品模块：

```text
TPS61088 固定5V模块 × 1
P-MOS 高边成品模块 × 1，必须支持 3.0-4.2V
SS12D07VG4 × 1，仅控制成品模块的 EN/CTRL
如果找不到合格成品模块，再改用 AO3415、100k 和 1k 离散方案
```

```text
500mAh 电池 B+ -> PH2.0 2P -> TP4057 BAT+
500mAh 电池 B- -> PH2.0 2P -> TP4057 BAT-

TP4057 另一组 BAT+ -> P-MOS高边模块 VIN+
P-MOS高边模块 VOUT+ -> TPS61088 升压 IN+
TP4057 另一组 BAT- -> P-MOS高边模块 GND -> TPS61088 IN-

SS12D07VG4 公共脚 -> P-MOS高边模块 EN/CTRL
P-MOS高边模块 EN/CTRL 的参考电平必须按模块说明连接
开关的另一端接 GND 或 VIN+，取决于模块是高有效还是低有效

TPS61088 OUT+ 5V -> ESP32 5V
TPS61088 OUT-    -> ESP32 GND
```

规则：

- 开关只控制成品 P-MOS 高边模块的 EN/CTRL，不串联承载升压输入电流。
- 成品模块必须是高边 PMOS，不能使用会切断公共地的 N-MOS 低边模块。
- 成品模块必须能在 3.0 到 4.2V 输入范围内可靠导通，额定电流至少 1A。
- F5305S 标注受控输出 5-36V，不适合 3.0-4.2V 电池路径，已排除。
- 可选 SS-12E07G4 3A 开关直接串在电池正极；下单前必须确认额定值和 DC 低电压使用条件。
- 下单前必须确认模块具有适合机械开关控制的 EN/CTRL 端，而不是只支持脉冲触发或 5V 逻辑。
- 如果模块是低有效，SS12D07VG4 将 EN/CTRL 拉至 GND 为开，断开为关。
- 如果模块是高有效，按模块说明将 EN/CTRL 拉到 VIN+；不能凭经验直接反接。
- TPS61088 自带的 EN 焊盘不需要额外购买控制模块；固定 5V 模式下可将 EN 保持接 VIN。
- TPS61088 的 EN 关闭时只是关闭升压，输出仍可能接近或略低于输入，不能把它当作彻底断电开关。
- 真正的主电源断开由 P-MOS 高边模块完成，SS12D07VG4 控制该模块的 EN/CTRL。
- TPS61088 必须选择固定 5V 版，输入覆盖 3.0 到 4.2V，额定输出至少 1A，建议 2A。
- 客服确认有“跳线固定 5V”和“电位器调压”两种方式；本项目必须选前者，禁止使用电位器调到 5V 后长期佩戴。
- 客服已确认所选链接为固定电压版本，短接 5V 跳线后输出固定 5V，电位器和 ADJ 不参与调节。
- 3.0 到 4.2V 输入低于 5V 输出，符合该 Boost 模块的输入条件。
- TPS61088 是否带 EN 不影响本方案，主电源开关由 P-MOS 高边模块完成。
- 模块必须有板载输入和输出电容，并在空载时实测约 5.00V。
- TP4057 输出不是 5V，必须经过 TPS61088 升压模块。
- 开关不切换 3.3V。
- USB 烧录或导出时断开电池输出。
- 充电时关闭负载，第一版不要把封闭软袋直接放在无人看管的充电环境。

## 7. 应力释放

- 线束两端各留 1 到 2cm 缓冲弯。
- 每 3 到 5cm 用纸胶带、魔术贴或医用胶带固定。
- PH2.0 插头前后不能直接承受传感器惯性拉力。
- 传感器盒入口处先固定线束，再进入盒子。
- 前臂软袋入口处固定线束，USB-C 口不受线缆拉力。
- 快速挥臂时，插头、焊点和 ICM 排针不能出现可见位移。

## 9. H2 测试步骤

### 测试 A：接口静态检查

```text
1. 只使用 USB 给 ESP32 供电。
2. 不接电池和升压模块。
3. 软件读取 WHO_AM_I。
4. 预期返回 0xEA。
5. 固定 I2C 50kHz 和地址 0x68。
```

通过条件：

- [ ] 地址 `0x68`。
- [ ] `WHO_AM_I=0xEA`。
- [ ] 无通信异常。

### 测试 B：10 秒静止测试

```text
1. 固定传感器和线束。
2. 保持静止。
3. 使用 F4 固件短按 BOOT 记录 10 秒。
4. 导出并检查数据。
```

通过条件：

- [ ] 采样率约 220-225Hz。
- [ ] 最大采样间隔不超过 10ms。
- [ ] 无复位。
- [ ] 无全零。
- [ ] 无固定饱和。
- [ ] 无削顶。

### 测试 C：小幅动态测试

```text
1. 缓慢屈伸腕部、旋转前臂和摆臂。
2. 检查连接器和线束是否松动。
3. 再次执行 10 秒记录。
```

通过条件：

- [ ] 无复位。
- [ ] 无全零。
- [ ] 无固定饱和。
- [ ] 无削顶。
- [ ] 最大采样间隔不超过 10ms。
- [ ] 接头和焊点没有位移。

## 11. 已知风险

- 3.7V 转 5V 升压模块尚未购买，当前无法完成电池供电验证。
- TPS61088 必须选固定 5V SKU，不能用只有电位器且没有电压指示的版本。
- 首版只需要 1 个 TPS61088；第二个只作为备用，不影响功能验收。
- SS12D07VG4 不适合串联在升压输入电流路径，只允许用于 P-MOSFET 栅极控制。
- 使用合格成品 P-MOS 高边模块时，100k 和 1k 通常已经集成，不需要重复焊接。
- 如果成品模块无法明确支持 3.0V 输入，则回到 AO3415 离散方案，并焊接 100k 和 1k。
- 成品模块的 EN/CTRL 极性和参考电平必须在接线前用万用表确认。
- 成品模块在 3.0V 输入附近必须实测导通压降，避免高边开关损耗过大。
- H2 实物尚未装配，所有机械和测试结果均为待验证。
- `10cm × 8cm` 软袋对前臂偏大，真实投篮时可能晃动。
- `10cm × 7cm × 2.3cm` 主控盒不适合佩戴，只能做收纳和台架。
- 26AWG 线只有黑红两色，SDA 和 SCL 必须靠标签区分。
- TP4057 是充电板，需要确认 Type-C 口在前臂软袋中的可访问性。
- 快速动作时，PH2.0 插头可能承受拉力，必须实际验证应力释放。
- NCS 和 AD0 如果焊点断开，可能出现地址漂移或通信异常。
- 任何接口变更都必须由软件对话批准并更新基线文件。
