## 2. 固定接口

```text
ICM VCC  -> ESP32 3V3
ICM GND  -> ESP32 GND
ICM SDA  -> ESP32 GPIO8
ICM SCL  -> ESP32 GPIO9
ICM NCS  -> ESP32 3V3
ICM AD0  -> ESP32 GND

I2C address = 0x68
I2C clock   = 50kHz
WHO_AM_I    = 0xEA
```

禁止：

- `0x69` 或 `0x0C` 作为长期主地址。
- `NCS` 或 `AD0` 悬空。
- 切换或旁路 3.3V 电源路径。
- 改为软件未批准的连接器线序。

## 3. 连接器和线序

连接器：PH2.0 2.0mm 4P 公母带线。

```text
Pin 1 = VCC = 3V3
Pin 2 = GND = 公共地
Pin 3 = SDA = GPIO8
Pin 4 = SCL = GPIO9
```

ICM 端就近固定：

```text
ICM NCS -> 3V3
ICM AD0 -> GND
```

NCS 和 AD0 固定后不需要 6P 连接器。4P 线长优先 10 到 15cm，最多先不超过 20cm。焊接后用万用表逐根检查，不能只靠线色。

## 4. 接线图

```text
                         +----------------+
ESP32-S3 3V3 -----------| PH2.0 4P Pin 1 |-------- ICM VCC
ESP32-S3 GND -----------| PH2.0 4P Pin 2 |-------- ICM GND
ESP32-S3 GPIO8 ---------| PH2.0 4P Pin 3 |-------- ICM SDA
ESP32-S3 GPIO9 ---------| PH2.0 4P Pin 4 |-------- ICM SCL

ESP32-S3 3V3 ------------------------------ ICM NCS
ESP32-S3 GND ------------------------------ ICM AD0

ICM-20948 和 ESP32-S3 必须共地
```

## 5. 机械固定

### 腕部传感器单元

- ICM 放入 `5cm × 3.5cm × 1.8cm` 小盒。
- 盒底贴 2mm EVA。
- 盒子背面贴魔术贴，固定到 3.8cm 腕带。
- 位置：腕横纹向上约 2 到 4cm。
- 盒子画箭头，箭头始终朝向手肘。

### 前臂电源和主控单元

- 第一版把 ESP32、TP4057、电池放入 `10cm × 8cm` 布艺软袋。
- 前臂使用 5cm 绑带，位置约在腕横纹向上 6 到 10cm，避开肘窝。
- `10cm × 7cm × 2.3cm` 主控盒只用于运输和台架测试，不作为投篮佩戴外壳。
- 袋内电池和主板之间加 EVA 或薄泡棉，防止互相撞击。

## 6. 电源路径和开关

最低工作量替代方案：

```text
TP4057 输出 BAT+ -> SS-12E07G4 3A开关 -> TPS61088 IN+
TP4057 输出 BAT- ----------------------> TPS61088 IN-
```

候选 SS-12E07G4 开关标称 `3A 250VAC / 5A 125VAC`，接触电阻 `≤50mΩ`。在 3.7V、1A 的低压工况下电气余量足够，确认 ON-ON 保持型后可直接使用，不需要 P-MOS、100k、1k 或 AO3415。

当前主方案：

```text
500mAh 电池 B+ -> PH2.0 2P -> TP4057 BAT+
500mAh 电池 B- -> PH2.0 2P -> TP4057 BAT-

TP4057 另一组 BAT+ -> SS-12E07G4 3A开关 -> TPS61088 IN+
TP4057 另一组 BAT- ----------------------> TPS61088 IN-

TPS61088 OUT+ 5V -> ESP32 5V
TPS61088 OUT-    -> ESP32 GND
```

规则：

- SS-12E07G4 直接串在电池正极主路径，额定 3A，满足当前 1A 目标。
- 原 SS12D07VG4 0.5A 开关不再用于主电流路径，只作为备用或低电流控制。
- TPS61088 的 EN 不需要作为主开关；EN 关闭只是关闭升压，不是完全断开输出。
- TPS61088 必须选择固定 5V 版，输入覆盖 3.0 到 4.2V，额定输出至少 1A，建议 2A。
- 穿戴版优先选择焊盘版 TPS61088；KF301 螺丝端子版会增加重量和厚度，只建议台架使用。
- 客服确认有“跳线固定 5V”和“电位器调压”两种方式；本项目必须选前者，禁止使用电位器调到 5V 后长期佩戴。
- 客服已确认所选链接为固定电压版本，短接 5V 跳线后输出固定 5V，电位器和 ADJ 不参与调节。
- 3.0 到 4.2V 输入低于 5V 输出，符合该 Boost 模块的输入条件。
- 模块必须有板载输入和输出电容，并在空载时实测约 5.00V。
- TP4057 输出不是 5V，必须经过 TPS61088 升压模块。
- 开关不切换 3.3V。
- USB 烧录或导出时断开电池输出。
- 充电时关闭负载，第一版不要把封闭软袋直接放在无人看管的充电环境。

如果 SS-12E07G4 的 DC 评级无法确认，才回退到低压高边 P-MOS 或 AO3415 离散方案；F5305S 5-36V 模块已排除。

## 6.1 TPS61088 与现有配件兼容性

已选固定 5V TPS61088 版本与本项目其余配件的对应关系：

| 环节 | 参数 | 兼容性 | 条件 |
|---|---|---|---|
| 电池 -> TP4057 | 3.7V 500mAh，1C持续/2C峰值，最大充电1C | 兼容 | 持续放电500mA，峰值1A；过流保护点未知，启动峰值需实测 |
| TP4057 -> 3A开关 | 4.2V 以下，负载约 0.5 到 1A | 兼容 | 开关使用电池正极主路径 |
| 3A开关 -> TPS61088 | 3.0 到 4.2V 输入 | 兼容 | 开关额定 3A，余量足够 |
| TPS61088 -> ESP32 | 固定 5V 输出 | 兼容 | 接 ESP32 5V 与 GND |
| ESP32 -> ICM | 3.3V、GPIO8、GPIO9 | 兼容 | 不改变 NCS、AD0 和 I2C 基线 |
| PH2.0 2P -> 电池 | 约 0.5 到 1A 稳态 | 兼容 | 峰值上电电流需实测 |
| PH2.0 4P -> ICM | 4 根信号和电源线 | 兼容 | 线序固定 VCC/GND/SDA/SCL |
| TPS61088 -> 前臂软袋 | 40 × 22mm，焊盘版 | 兼容 | 优先焊盘版，端子版更厚 |

需要下单前确认：

- [ ] 商品 SKU 为 `TPS61088(5V)` 固定电压版本。
- [ ] 固定 5V 通过短接 5V 跳线实现，不依赖电位器长期保持。
- [ ] 优先发货焊盘版，不是 KF301 螺丝端子版。
- [x] 电池保护板持续放电 `1C = 500mA`，峰值 `2C = 1A`，最大充电 `1C = 500mA`。
- [ ] 过流保护点未知，TPS61088 启动峰值不能长期接近或超过 1A。
- [ ] 不要因为 TPS61088 标称 2A 就用 500mAh 电池长期跑满 2A；当前电池持续上限只有 500mA。
- [ ] 模块 EN 不作为主电源开关，主开关仍使用 SS-12E07G4。
- [ ] 输出先空载测 5.00V，再带 ESP32 启动测试，不得低于约 4.85V。

## 7. 应力释放

- 线束两端各留 1 到 2cm 缓冲弯。
- 每 3 到 5cm 用纸胶带、魔术贴或医用胶带固定。
- PH2.0 插头前后不能直接承受传感器惯性拉力。
- 传感器盒入口处先固定线束，再进入盒子。
- 前臂软袋入口处固定线束，USB-C 口不受线缆拉力。
- 快速挥臂时，插头、焊点和 ICM 排针不能出现可见位移。

## 9. H2 测试步骤

### 测试 A：接口静态检查

```text
1. 只使用 USB 给 ESP32 供电。
2. 不接电池和升压模块。
3. 软件读取 WHO_AM_I。
4. 预期返回 0xEA。
5. 固定 I2C 50kHz 和地址 0x68。
```

通过条件：

- [ ] 地址 `0x68`。
- [ ] `WHO_AM_I=0xEA`。
- [ ] 无通信异常。

### 测试 B：10 秒静止测试

```text
1. 固定传感器和线束。
2. 保持静止。
3. 使用 F4 固件短按 BOOT 记录 10 秒。
4. 导出并检查数据。
```

通过条件：

- [ ] 采样率约 220-225Hz。
- [ ] 最大采样间隔不超过 10ms。
- [ ] 无复位。
- [ ] 无全零。
- [ ] 无固定饱和。
- [ ] 无削顶。

### 测试 C：小幅动态测试

```text
1. 缓慢屈伸腕部、旋转前臂和摆臂。
2. 检查连接器和线束是否松动。
3. 再次执行 10 秒记录。
```

通过条件：

- [ ] 无复位。
- [ ] 无全零。
- [ ] 无固定饱和。
- [ ] 无削顶。
- [ ] 最大采样间隔不超过 10ms。
- [ ] 接头和焊点没有位移。

## 11. 已知风险

- 3.7V 转 5V 升压模块尚未购买，当前无法完成电池供电验证。
- TPS61088 必须选固定 5V SKU，不能用只有电位器且没有电压指示的版本。
- 首版只需要 1 个 TPS61088；第二个只作为备用，不影响功能验收。
- SS12D07VG4 不适合串联在升压输入电流路径，只允许用于 P-MOSFET 栅极控制。
- 使用合格成品 P-MOS 高边模块时，100k 和 1k 通常已经集成，不需要重复焊接。
- 如果成品模块无法明确支持 3.0V 输入，则回到 AO3415 离散方案，并焊接 100k 和 1k。
- 成品模块的 EN/CTRL 极性和参考电平必须在接线前用万用表确认。
- 成品模块在 3.0V 输入附近必须实测导通压降，避免高边开关损耗过大。
- H2 实物尚未装配，所有机械和测试结果均为待验证。
- `10cm × 8cm` 软袋对前臂偏大，真实投篮时可能晃动。
- `10cm × 7cm × 2.3cm` 主控盒不适合佩戴，只能做收纳和台架。
- 26AWG 线只有黑红两色，SDA 和 SCL 必须靠标签区分。
- TP4057 是充电板，需要确认 Type-C 口在前臂软袋中的可访问性。
- 快速动作时，PH2.0 插头可能承受拉力，必须实际验证应力释放。
- NCS 和 AD0 如果焊点断开，可能出现地址漂移或通信异常。
- 任何接口变更都必须由软件对话批准并更新基线文件。
